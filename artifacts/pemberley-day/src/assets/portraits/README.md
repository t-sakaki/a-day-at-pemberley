# 差し込み用の肖像画像

ここに `<id>-<表情>.png`（jpg / webp も可）を置くと、左パネルのキャラクターカード・
手紙の差出人・芝生を歩く来客の顔がその画像に差し替わります。
画像が無いキャラクターは描き顔（`LivingPortrait`）にフォールバックします。

## 表情

`calm`（平常） / `pleased`（好意的） / `concerned`（当惑） / `tense`（緊張・こわばり）

`<id>-calm.png` だけでも可。指定の表情が無ければ `calm` → 最初に見つかった1枚の順で使われます。
`<id>.png`（表情なし）も1枚絵として認識します。

## 仕様

- 正方形、顔中心のトリミング。表示は 38〜46px なので **256px 四方以上**あると綺麗です。
- 背景は単色か透過。カードでは円形にマスクされます（`object-position: center top`）。
