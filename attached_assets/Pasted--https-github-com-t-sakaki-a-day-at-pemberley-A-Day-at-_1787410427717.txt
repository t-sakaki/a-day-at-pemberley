【プロジェクト概要】
リポジトリ: https://github.com/t-sakaki/a-day-at-pemberley
既存の「A Day at Pemberley」（React + Vite + TypeScript + Three.js）を、以下の3つの観点で大幅に改修してください。

【改修要件A: 18世紀イギリス水彩画・ピクチャレスク風の視覚表現】
現状のポリゴン/リアル調3Dを、18世紀イギリスの透明水彩画（watercolor）とピクチャレスク（Picturesque）風景画の美学に基づいた視覚表現に変更します。日本の水墨画や掛け軸とは完全に無関係です。

実装方針:

1. カラーパレット制約（全マテリアル）:
   すべてのオブジェクト色を、18世紀イギリス水彩画のパレットに厳密に制限します：
   - 空: #a8b8c8（くすんだセルリアンブルー）
   - 遠景/山: #9aa8b0（青みがかったグレー、空気遠近法）
   - 樹木: #4a5d3f（セージグリーン）、#6b4c2e（枯れ木のオークル）
   - 草地: #7a8f5e（くすんだグリーン）、#b8a878（枯れた草）
   - 建物（石造り）: #c4b5a0（ストーン）、#8b7d6b（影のある石）
   - 屋根: #5a5a5a（スレートグレー）
   - 土/小道: #a89070（オークル）、#8b7355（濡れた土）
   - 花壇: #c9a0b0（くすんだローズ）、#d4b896（クリーム）
   - 影: #6a5a4a（暖かみのある濃色。純粋な黒を使わない）
   - 光: #fff8e7（キャンドル/太陽の暖かい光）
   既存のマテリアル色を上記に置き換え、彩度を下げ、透明感を出す。

2. Post-Processing Pipeline:
   Three.js の EffectComposer を導入し、以下のパスを適用:
   a) AtmosphericFogPass: 遠景を #c8d0d8 のフォグで霞ませる。距離に応じてオブジェクトが青みを帯び、空気遠近法（atmospheric perspective）を表現。
   b) WatercolorPaperPass: 2D Canvas で生成した微細ノイズテクスチャ（18世紀のラフな水彩紙の質感）をアルファブレンドで重ねる。色が紙に染み込むような質感。
   c) SoftVignettePass: 画面四隅に楕円形の暗いヴィネット。18世紀の Claude Glass（黒い凸面鏡）を覗き込むような「絵画的構図」を意識させる演出。
   d) EdgeSofteningPass: 軽いガウシアンブラー（半径1-2px）でエッジをわずかにぼかし、水彩画の「にじみ」を表現。
   e) ColorGradingPass: 彩度を10-15%下げ、コントラストを抑え、全体的に古い絵画の色温度に。

3. ライティングの再設計:
   - DirectionalLight（太陽）: intensity 0.5、色 #fff0d0。SoftShadowMap を有効化し、影の境界をぼかす。
   - AmbientLight: intensity 0.6（高め）。水彩画では影の中にも光があるため。
   - HemisphereLight: 空 #a8b8c8、地面 #7a8f5e。自然な空間グラデーション。
   - 室内 PointLight（暖炉/シャンデリア）: 色 #ffcc88、intensity 0.8。暖かみのある影を作る。
   - 夜間は DirectionalLight を弱め、PointLight を強調。キャンドルライトの揺らぎをシミュレート。

4. ピクチャレスク構図の演出:
   - 庭園に「荒れた木（gnarled tree）」を配置: 幹をねじれた円柱で表現。ピクチャレスクの「美しい荒廃」を象徴。
   - 小道はまっすぐではなく緩やかに蛇行（serpentine path）。ギルピンが称賛した「曲がりくねった美」。
   - 特定の「絵画的スポット」（丘の上、庭園の端、橋の上）に立つと、カメラがわずかにオート調整され、構図が三分割法に近づく（カメラの目標角度をスムーズに補間）。

5. ジオメトリの調整:
   - 木の葉は球体ではなく、水彩画の「葉の塊」を想起させる不規則なポリゴン群。
   - 建物の石壁は、わずかにランダムに頂点をずらし、手で描かれたような揺らぎを出す。

【改修要件B: 自然音・世界観音声の強化】
Web Audio API を使用し、5層の環境音システムを構築。

実装方針:
1. AudioManager クラスの作成:
   class AudioManager {
     // Layer 1: 基盤音（常時ループ）
     playWindNoise(); // フィルタード・ホワイトノイズ（BiquadFilterNode: lowpass, 400Hz）
     playRiverAmbience(); // 低周波サイン波（80Hz）+ 微細な周波数変調
     
     // Layer 2: 時間帯音（スケジュール連動）
     playMorningBirds(); // 6-9時: 短いチープ音（OscillatorNode, square wave, 短いエンベロープ）をランダム間隔（2-8秒）で発生
     playDayGardenSounds(); // 9-17時: 蜂の羽音（高速の周波数変調、100-200Hz）を庭園エリアに近づくと音量UP
     playEveningCrickets(); // 17-21時: パルス音（50ms ON / 200ms OFF の繰り返し）
     playNightOwls(); // 21-6時: 低いホーホー音（サイン波、200Hz→150Hzのスライド、2秒間隔）
     
     // Layer 3: 天候音
     playRain(); // 雨: ノイズ（ゲインを0.3、BiquadFilter: lowpass 800Hz）
     playThunder(); // 雷: 低周波のサイン波スイープ（40Hz→10Hz、0.5秒、ゲイン急上昇→急降下）
     
     // Layer 4: 位置連動音（3D定位）
     playCarriageWheels(); // 馬車音: 邸宅に近づくと音量増（距離に応じたゲイン調整）
     playKitchenSounds(); // 台所音: 鍋の音（ノイズバースト）、包丁の音（高周波クリック）
     
     // Layer 5: プロシージャル音楽
     playProceduralPiano(); // 18世紀風ピアノ。ペンタトニック音階（C-D-E-G-A）でアルペジオ。和音進行: I-V-vi-IV。ゲインを低め（0.15）で常時ループ。
   }

2. TTS（Web Speech API）強化:
   - 言語: en-GB（英国英語）をデフォルトに。
   - イベント発話:
     * レディ・キャサリン到着: "Her Ladyship has arrived without notice!" （rate: 0.85, pitch: 0.9, 威厳ある声）
     * 召使い報告: "Madam, the east room is prepared." （rate: 1.0, pitch: 1.0）
     * 不満警告: "The drawing room is quite unacceptable!" （rate: 1.1, pitch: 1.2, 焦りを表現）
     * 1日終了: "Another day at Pemberley has concluded." （rate: 0.9, pitch: 1.0）
   - 発話は、ユーザーが初回クリック後に有効化（ブラウザ自動再生ポリシー対策）。
   - 設定画面で「音声 ON/OFF」「音声速度（0.5-2.0）」をスライダーで調整可能に。

3. 自然音の世界観演出:
   - 朝の鳥の声は、ゲーム内6時ちょうどに「一斉に」鳴き始める（コーラス効果）。
   - 雨の日は、庭園エリアの環境音が「濡れた土の音」に変化（低周波ノイズを追加）。
   - 来客が邸宅に入ると、玄関ホールに「靴音の反響音」（短いディレイエフェクト）を追加。

【改修要件C: スマホ（タッチ）対応】
完全なタッチインターフェースを実装。

実装方針:
1. 仮想ジョイスティック:
   - 画面左下に半透明の円（直径120px）を配置。
   - タッチ開始位置を中心とし、指の移動方向に応じてプレイヤーが移動。
   - 最大移動半径は60px。離れた分だけ移動速度が比例（Analog入力）。
   - ジョイスティックは、タッチ時のみ表示（非アクティブ時は30%透明度）。

2. カメラ操作:
   - 画面右半分（x > 50%）のスワイプ: カメラ回転（OrbitControls のタッチ対応）。
   - ピンチイン/アウト: カメラズーム（2点タッチの距離変化を検出）。
   - シングルタップ（右半分）: その地点を注視点にスムーズ移動。

3. アクションボタン:
   - 画面右下に円形ボタン（直径80px、半透明、白い枠線）。
   - 「E」または「Talk」アイコンを表示。
   - タップで「話す/調べる/指示」アクションを発動。
   - 長押し（0.5秒）で「鐘を鳴らす」。

4. UIレスポンシブ:
   - すべてのUI要素に `touch-action: none` を設定。
   - タッチターゲットは最低44x44px。
   - フォントサイズは `clamp(12px, 2.5vw, 16px)` で可変。
   - モバイル時、ミニマップを画面左上に縮小（80x80px）。
   - イベントログは、モバイルでは画面下部にスワイプで展開/折りたたみ可能なパネルに。

5. モバイルパフォーマンス最適化:
   - タッチデバイス検出（'ontouchstart' in window）:
     * シャドウ解像度を 1024→512 に低下。
     * ポストプロセスのぼかし強度を半減。
     * `renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))` で retina 対応しつつ過剰レンダリングを防止。
     * FPS を 30 に制限（setTimeout ではなく、Three.js の setAnimationLoop で制御）。

【改修要件D: ジェイン・オースティン世界観の深化（追加演出）】
1. 手紙の演出:
   - 1日終了時の日記画面を、18世紀風の手紙（letter）に変更。
   - 手紙の紙は薄い黄色（経年変化 #f5f0e6）、フォントは18世紀筆記体（Google Fonts: 'Tangerine' または 'Great Vibes'）。
   - 封蝋のシールアニメーションで開封演出。

2. ピアノ演奏ミニゲーム:
   - 居間にピアノオブジェクトを追加。E/タップでミニゲーム開始。
   - 画面下部に4つの鍵盤が表示され、降ってくるノートをタップ/キーで演奏。
   - 曲はプロシージャル生成の18世紀風メロディ。

3. 散歩イベント:
   - 庭園の「散策ポイント」に近づくと、画面に短い詩的なテキストがフェードイン（例: "The laurels stood in quiet dignity against the morning mist."）。
   - テキストは時間帯・季節・天候で変化。全50パターン以上。

4. 服装の季節変化:
   - 季節に応じてNPCの服装色が変化（春：パステル、夏：白、秋：茶色、冬：濃紺）。
   - 雨の日は傘（黒い円盤）を持つ。

【技術制約】
- 既存の React + Vite + TypeScript + Three.js 構成を維持。
- 新規パッケージ追加は可能（three/postprocessing など）。
- 単一リポジトリ内で完結。外部API（画像・音声アセット）は使用しない（すべてプロシージャル生成）。
- コードは型安全（TypeScript）を維持し、any の乱用を避ける。
- 既存のクラス構成（AudioManager, TimeSystem, Staff, Player など）を尊重し、拡張形で実装。

【実装順序の提案】
1. カラーパレット統一とライティング再設計（最も視覚的インパクトがあるため）
2. Post-Processing Pipeline（水彩紙質感、フォグ、ヴィネット）
3. スマホタッチ対応（ユーザーベース拡大のため）
4. 自然音システムの強化（世界観補完）
5. TTS 強化・追加演出（最終仕上げ）

【出力形式】

- 各ファイルの先頭に「変更概要」のコメントを付記。
- 新規ファイルは `src/effects/AtmosphericFogPass.ts` などの命名規則。
