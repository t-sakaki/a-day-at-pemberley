【緊急修正依頼：視覚の「水彩画風化」とキャラクターの拡大】
リポジトリ: https://github.com/t-sakaki/a-day-at-pemberley
前回のEffectComposer/カスタムシェーダー/複雑な音声システムはすべて削除済みとします。
以下の5点のみを、確実に動作する形で修正してください。
「ポリゴンが小さくて誰が誰だか分からない」「水彩画に見えない」という不満を解決します。

【修正1: CSSフィルターで全体を絵画的に — 最優先】
ゲームの canvas 要素（または canvas を包む div）に以下のCSSを適用してください：
  filter: contrast(0.9) saturate(0.75) sepia(0.08);
これにより、鮮やかなCG色がくすみ、18世紀の透明水彩画に近い色温度になります。

【修正2: Fog（霧）を濃くして輪郭を溶かす】
scene.fog の設定を以下に変更：
  new THREE.FogExp2(0xd8d4c8, 0.04)
現在より密度（第二引数）を上げ、遠景の建物や木の輪郭が完全に霞むようにしてください。
これにより、角張ったポリゴンの輪郭が目立たなくなります。

【修正3: マテリアルを「光沢なし」に統一】
すべての MeshStandardMaterial を MeshLambertMaterial に置き換えてください。
理由: 水彩画に鏡面反射（光沢）はありません。Lambertは拡散反射のみで、平面的で柔らかな質感になります。
建物、木、地面、キャラクターすべてに適用。

【修正4: キャラクターを2倍に拡大、カメラを目線高さに】
1. キャラクターのスケール:
   - すべてのキャラクターメッシュ（召使い、来客、プレイヤー）の scale を (2, 2, 2) に変更。
   - 来客（レディ・キャサリンなど）は (2.5, 2.5, 2.5) にして、地位の高さを表現。

2. カメラ初期位置の変更:
   - 現在の高い俯瞰視点から、人の目線高さ（y: 1.6）に近づける。
   - 初期位置: camera.position.set(0, 1.6, 8);
   - lookAt: (0, 1.0, 0) — 人の顔の高さを見る。

3. ズーム機能:
   - マウスホイールでカメラの z 距離を 3（ズームイン最大）〜 15（ズームアウト最大）の範囲で調整。
   - スマホではピンチイン/アウトで同様。
   - 滑らかに移動: 毎フレーム lerp(current, target, 0.1)。

【修正5: 空をグラデーションに】
scene.background を単色ではなく、CanvasTexture のグラデーションに変更：
  const canvas = document.createElement('canvas');
  canvas.width = 2; canvas.height = 512;
  const ctx = canvas.getContext('2d');
  const g = ctx.createLinearGradient(0, 0, 0, 512);
  g.addColorStop(0, '#a8b8c8');   // 上: 青みがかった空
  g.addColorStop(0.5, '#d8c8b0'); // 中: 夕暮れのベージュ
  g.addColorStop(1, '#f0e8d8');   // 下: 地平線の暖かい光
  ctx.fillStyle = g;
  ctx.fillRect(0, 0, 2, 512);
  scene.background = new THREE.CanvasTexture(canvas);

【修正6: 輪郭線（Edge）の削除】
もし EdgesGeometry や LineSegments で輪郭線を描画している箇所があれば、すべて削除してください。
水彩画に黒い輪郭線はありません。

【修正7: ソフトシャドウ】
renderer.shadowMap.type = THREE.PCFSoftShadowMap; を設定済みか確認。
未設定の場合は追加。影の境界をぼかします。

【重要】
- 上記7点のみを実装。新しいライブラリ（postprocessing等）は追加しない。
- 既存のReact+Vite+TypeScript構成を維持。
- コンソールにエラーが出ないことを確認。
- 変更後、キャラクターが「小さなポリゴン」ではなく「目の前に立つ人」として見えることを確認。
- ビルド後、ブラウザで確認できる状態にしてください。
